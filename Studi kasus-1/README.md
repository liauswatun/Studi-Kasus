# Studi Kasus Zoom ke-1: Analisis Penjualan dan Laba

## Latar belakang
Materi Zoom ke-1 membahas cara mengolah data menjadi informasi yang membantu pengambilan keputusan bisnis. Contoh masalahnya adalah pendapatan meningkat, tetapi laba bersih menurun dan piutang bertambah.

## Permasalahan
Bagaimana melihat perubahan pendapatan, laba bersih, dan piutang dari waktu ke waktu serta menentukan hal yang perlu diperiksa lebih lanjut?

## Solusi
Dashboard web sederhana dengan ringkasan angka, grafik bulanan yang dapat diganti metriknya, perbandingan awal-akhir periode, dan kesimpulan awal.

## Data
Data dibuat secara simulasi untuk latihan. Ini bukan dataset asli pemateri atau data asli perusahaan.

## Teknologi
HTML, CSS, JavaScript, dan Chart.js melalui CDN.

## Cara menjalankan
1. Ekstrak ZIP dan buka folder proyek di VS Code.
2. Pastikan internet aktif agar Chart.js dapat dimuat.
3. Buka `index.html` di browser. Alternatifnya, gunakan ekstensi Live Server di VS Code lalu pilih **Open with Live Server**.
4. Pilih metrik Pendapatan, Laba bersih, atau Piutang untuk mengubah grafik.

Tidak perlu memasang Python, PHP, atau database.

## Alur analisis
1. Memahami masalah bisnis.
2. Menyiapkan data contoh.
3. Membuat ringkasan dan visualisasi.
4. Membaca pola awal.
5. Menentukan analisis lanjutan sebelum mengambil keputusan.

## Hasil yang diharapkan
Dashboard menunjukkan pendapatan cenderung meningkat, laba bersih menurun, dan piutang bertambah pada data simulasi. Ini adalah sinyal untuk memeriksa biaya, margin, diskon, dan pembayaran pelanggan. Analisis ini belum membuktikan penyebab pasti.

## Upload ke GitHub
1. Login ke https://github.com.
2. Klik **New repository** dan beri nama `studi-kasus-zoom-1-analisis-bisnis`.
3. Buat repository.
4. Pilih **Add file → Upload files**.
5. Unggah file proyek (`index.html`, `style.css`, `app.js`, `README.md`, dan `.gitignore`).
6. Isi pesan commit, misalnya `Tambah studi kasus analisis bisnis Zoom 1`.
7. Klik **Commit changes**.

Proyek ini belum diunggah ke akun GitHub pengguna; langkah di atas adalah panduan upload.
