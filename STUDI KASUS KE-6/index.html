Pemantauan Perubahan Tutupan Hutan

Dashboard latihan untuk meninjau indikasi gangguan hutan dan mengelompokkan kemungkinan penyebabnya.

Penting: data dalam dashboard ini adalah data simulasi untuk latihan. Ini bukan citra satelit Sentinel-1/Sentinel-2, bukan data deforestasi resmi, dan bukan hasil model CNN yang sudah dilatih.

Alur kerja yang dijelaskan dalam materi

  1. Gunakan citra satelit untuk mendeteksi perubahan tutupan hutan.
  2. Sentinel-2 menyediakan citra optik, tetapi pengamatan dapat terganggu awan.
  3. Sentinel-1 menggunakan radar dan dapat melengkapi pengamatan saat berawan.
  4. Model AI seperti CNN dapat membantu mengelompokkan pola gangguan berdasarkan data latih berlabel.
  5. Evaluasi hasil, termasuk macro F1-score, dan lakukan pemeriksaan lapangan bila diperlukan.
  6. Untuk peringatan kebakaran yang cepat, gunakan data sensor termal sebagai pelengkap; dashboard ini sendiri tidak mendeteksi api secara langsung.

Batasan hasil

Perubahan tutupan lahan pada citra tidak selalu memastikan penyebabnya. Gangguan akibat aktivitas manusia dan kejadian alami dapat terlihat mirip. Karena itu, hasil klasifikasi perlu diperiksa, dan akurasi keseluruhan sebaiknya dilihat bersama macro F1-score agar kategori yang jarang muncul tidak terabaikan.
